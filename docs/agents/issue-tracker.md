# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues on `bogachev-alex/viva_la_circle`.

## Conventions

- Specs and implementation tickets are GitHub issues
- Triage state uses labels from `docs/agents/triage-labels.md`
- PRs as a request surface: **off**

## When a skill says "publish to the issue tracker"

Create a GitHub issue with `gh issue create` and apply the appropriate triage label.
